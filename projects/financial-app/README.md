# Financial App

Calculates monthly salaries for a few employees from the hourly price, tax rate and working hours.

## Concepts used
- Variables and data types (`double`)
- Arithmetic operators and percentages
- Formatted console output

## Run
```bash
g++ main.cpp -o financial_app
./financial_app
```

## Next steps
